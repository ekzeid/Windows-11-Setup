### Сделай из обычной Windows 11 систему, которой действительно приятно пользоваться.

Надоела стандартная Windows с кучей ненужных приложений, телеметрией, лишними службами и скучным интерфейсом? Здесь собрано всё, чтобы установить чистую Windows 11, настроить её под себя и сделать максимально удобной, красивой и быстрой.

**В этом репозитории ты найдёшь всё необходимое для полноценной настройки Windows 11:**

- **Чистая установка Windows 11** — файлы автоматической настройки установки, позволяющие пропустить часть стандартных этапов и избавиться от некоторых ненужных компонентов.
- **Оптимизация системы** — BAT-скрипты и утилиты для удаления лишних приложений, настройки Windows, отключения ненужных функций и уменьшения фоновой активности.
- **Красивый интерфейс** — инструменты для кастомизации панели задач, меню «Пуск», проводника, анимаций и других элементов системы.
- **Кастомные курсоры** — готовые наборы курсоров, которые можно установить вместо стандартных.
- **Обои** — подборка обоев в светлом и тёмном оформлении.
- **Приватность** — инструменты для управления телеметрией и другими настройками конфиденциальности Windows.
- **Полезные программы** — подобранные мной утилиты, браузеры, проигрыватели и другие приложения для повседневного использования.
- **Кастомизация Steam** — инструменты для установки тем, модов и изменения внешнего вида клиента Steam.

### Всё в одном месте

Не нужно часами искать программы, команды, скрипты и красивые курсоры по разным сайтам. Я собрал инструменты и файлы, которыми пользуюсь сам, в одном репозитории.

Здесь есть всё: от установки Windows с нуля до финальной настройки рабочего стола.

**Цель сборки — Windows 11 без лишнего мусора, с приятным интерфейсом, удобными функциями и настройками под себя.**

> **Важно:** Некоторые твики изменяют системные функции и параметры безопасности Windows. Перед применением рекомендую создать точку восстановления и внимательно выбирать настройки.
