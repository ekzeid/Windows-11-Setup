# Windows 11 Setup

### Turn your ordinary Windows 11 into a system you'll actually enjoy using.

Tired of the standard Windows experience with tons of unnecessary apps, telemetry, background services, and a boring interface? Here you'll find everything you need to install a clean Windows 11 system, customize it to your liking, and make it as convenient, beautiful, and fast as possible.

**In this repository, you'll find everything you need to fully customize Windows 11:**

- **Clean Windows 11 Installation** — automated installation files that let you skip certain setup steps and remove some unnecessary components.
- **System Optimization** — BAT scripts and utilities for removing unwanted apps, tweaking Windows settings, disabling unnecessary features, and reducing background activity.
- **Beautiful Interface** — tools for customizing the taskbar, Start menu, File Explorer, animations, and other system elements.
- **Custom Cursors** — ready-to-use cursor packs that you can install instead of the default ones.
- **Wallpapers** — a collection of wallpapers in light and dark styles.
- **Privacy** — tools for managing telemetry and other Windows privacy settings.
- **Useful Software** — a collection of utilities, browsers, media players, and other everyday applications that I recommend.
- **Steam Customization** — tools for installing themes, mods, and changing the appearance of the Steam client.

### Everything in One Place

No need to spend hours searching different websites for programs, commands, scripts, and custom cursors. I've collected the tools and files I personally use in one repository.

Everything is here, from installing Windows from scratch to putting the finishing touches on your desktop.

**The goal of this collection is simple: Windows 11 without unnecessary bloat, with a beautiful interface, useful features, and settings tailored to your preferences.**

> **Important:** Some tweaks modify system features and Windows security settings. I recommend creating a restore point and carefully choosing which settings to apply.
