# Настройка Windows 11 без лишнего

Моя инструкция по чистой установке и настройке Windows 11. В репозитории лежат файлы ответов, скрипты и дополнительные материалы, которыми я пользуюсь.

## Установка и настройка

**0)** Берём пустую флешку и переносим на неё файлы из репозитория. Для удобства лучше использовать **две флешки**: одну для установки Windows, вторую для остальных файлов и драйверов.

**1)** Создаём установочную флешку с Windows 11 через [официальный сайт Microsoft](https://www.microsoft.com/ru-ru/software-download/windows11). Советую флешку от **16 ГБ**. Проще использовать Media Creation Tool, чем отдельно скачивать ISO и записывать его через Rufus, хотя так тоже можно. **Внимание:** при создании установочного носителя данные с выбранной флешки могут быть удалены.

**2)** Копируем на установочную флешку **один** нужный файл ответов `autounattend.xml` из папки с русским или английским вариантом. Положить его нужно **в корень флешки**. Он автоматизирует часть установки Windows и меняет ряд стандартных настроек. Перед использованием учитывайте, что файл также затрагивает параметры безопасности.

**3)** На вторую флешку с файлами репозитория скачиваем драйверы для своего устройства, особенно сетевые (Wi-Fi или Ethernet). Лучше брать их с сайта производителя ноутбука или материнской платы.

**4)** Выключаем компьютер, оставляем установочную флешку подключённой и входим в **Boot Menu** при включении. Обычно для этого нажимают `F12`, `Esc`, `F9` или другую клавишу, в зависимости от устройства. Выбираем установочную флешку и проходим установку Windows. Если окно выбора языка не появилось, это *может* означать, что файл ответов применился, но само по себе не гарантирует, что все его настройки сработали.

**5)** После установки Windows устанавливаем драйверы со второй флешки. Остальные драйверы при необходимости можно получить через Центр обновления Windows или сайт производителя.

**6)** Открываем папку `Тулзы` на флешке с файлами репозитория. Там два BAT-файла:

- `explorer.bat` — настройка Проводника: позволяет убрать ненужные элементы интерфейса. Выбираем нужный пункт по цифре, описание есть в самом скрипте.
- `win-tweaker.bat` — дополнительные настройки Windows. В нём тоже есть пояснения к пунктам. **Не советую включать всё подряд:** некоторые режимы отключают защитные функции Windows, в том числе UAC и SmartScreen. Выбирайте только те изменения, которые действительно нужны.

**7)** Настраиваем остальное: регион, время, язык, обои, дисплей и другие личные параметры.

**8)** После установки нужных приложений чистим автозагрузку: `Ctrl + Shift + Esc` → **Автозагрузка приложений**. Отключаем то, что не должно запускаться вместе с Windows.

## Что советую установить

### Важные утилиты для настройки Windows

**1) [Mem Reduct](https://memreduct.org/)** — утилита для очистки некоторых областей оперативной памяти и системного кеша. Не удаляет процессы Windows и не гарантирует ускорение компьютера. Может пригодиться при нехватке ОЗУ.

**2) [All-Tweaker](https://github.com/scode18/All-Tweaker)** — набор инструментов для настройки Windows, удаления ненужных приложений и изменения системных параметров, в том числе связанных с телеметрией. Используйте выборочно: некоторые изменения могут затронуть работу системы.

**3) [Microsoft PowerToys](https://learn.microsoft.com/ru-ru/windows/powertoys/)** — набор утилит Microsoft для удобной настройки и расширения возможностей Windows. Можно установить через Microsoft Store.

### Приложения, которыми сам пользуюсь

**1) [Google App для Windows](https://search.google/google-app/desktop/)** — поиск Google с экрана по горячим клавишам.

**2) [Handy](https://handy.computer/)** — бесплатный инструмент голосового ввода: диктуешь текст, а он преобразует речь в текст.

**3) [Zen Browser](https://zen-browser.app/)** — лучший браузер. Менеджер модов для него — [Sine](https://github.com/CosmoCreeper/Sine). Лучший мод — **Nebula**: добавляет аккуратные анимации там, где нужно, и размытие.

**4) [Windhawk](https://windhawk.net/)** — программа для установки модификаций Windows. Советую следующие моды:

- **Taskbar Dock Animation** — анимации панели задач.
- **Windows 11 Start Menu Styler** — изменение внешнего вида меню «Пуск».
- **Dynamic Island for Windows** — динамический остров на рабочем столе.
- **OverhauledWin Alt+Tab** — изменение внешнего вида переключателя окон.

**5) [VLC](https://www.videolan.org/index.ru.html)** — лучший видеоплеер.

**6) [AIMP](https://aimp.ru/?do=download&os=windows)** — лучший аудиоплеер.

**7) [Millennium (SteamBrew)](https://steambrew.app/)** — утилита для установки модов и тем для Steam. Советую эти темы: `F4XgbtTW4x5CJmi5DUK3` и `uV8M1eg45Hh662blPuyD`.

**8) [SteamBooster](https://steambalance.cc/)** — утилита для пополнения кошелька Steam через SteamBalance прямо из клиента. В интернете встречаются заявления, что в ней могут быть вирусы, но часть исходного кода опубликована на [GitHub](https://github.com/STEAMBALANCE). Сам пользуюсь, проблем не замечал. При этом наличие кода на GitHub само по себе не гарантирует безопасность установщика.

Для быстрой установки обычных программ (браузеров, мессенджеров, плееров и т. д.) можно использовать [Ninite](https://ninite.com/): выбираем приложения и скачиваем один установщик. Доступны не все программы.

**Важно:** советую временно отключать антивирус Windows при установке некоторых утилит, например All-Tweaker или Sine, поскольку Защитник Windows может ругаться на программы, которые меняют системные настройки. Но сначала проверьте источник и причину предупреждения: срабатывание антивируса не всегда ложное. После установки сразу включите защиту обратно.

Вот и всё: установили Windows 11, убрали часть ненужных приложений и настроили систему под себя. Это может сделать работу удобнее, особенно на слабом ПК, но **гарантировать ускорение нельзя**: результат зависит от железа и выбранных настроек.
